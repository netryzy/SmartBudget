# 💸 SmartBudget Bot

Чат-бот для учета личных финансов с использованием AI.

## 🚀 Возможности

- 💰 Добавление доходов
- 💸 Добавление расходов (в свободной форме)
- 📊 Статистика (неделя / месяц / год)
- 📈 Сравнение с прошлым периодом
- 🤖 AI-парсинг текста
- ⚠️ Уведомления о перерасходе
- 📊 Графики расходов и доходов

---

## 🧠 Использование AI

AI используется для:

- Парсинга сложных пользовательских сообщений
- Определения категорий расходов
- Улучшения UX (понимание естественного языка)

---

## 🏗 Архитектура

- aiogram (Telegram Bot)
- SQLite (база данных)
- OpenAI API (AI обработка)
- matplotlib (графики)
